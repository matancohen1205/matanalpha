# רשימת הפעלה

הרצה: `npm run preflight` עם משתני הסביבה של הפרודקשן (ב-Render: Shell של השירות). הוא מדווח מה חוסם ומה אופציונלי.

## חובה לפני קבלת משתמשים
1. **דיסק קבוע:** `render.yaml` מגדיר דיסק ב-`/data` ו-`DB_PATH=/data/app.db` (דורש תוכנית בתשלום). השרת מסרב לעלות בפרודקשן בלי `DB_PATH` ו-`DATA_KEY`, כי חשבונות ופניות היו נמחקים.
2. **`DATA_KEY`:** נוצר אוטומטית. שמרו עותק במקום בטוח נפרד: בלעדיו אי אפשר לקרוא גיבוי, ואסור להחליף אותו אחרי שנשמרו נתונים.
3. **דומיין ו-`PUBLIC_URL`** בכתובת https (קישורי מייל, canonical, sitemap).
4. **SMTP:** `SMTP_URL`, `MAIL_FROM` (כתובת מאומתת אצל הספק). ראו `DEPLOY.md`.
5. **מפעיל אדם פרטי:** העמודים המשפטיים מנוסחים כך (ללא שם עסק/ח.פ./כתובת; יצירת קשר דרך הטופס). לפני שמרוויחים כסף מהאתר (מנוי Pro), בדקו מול רשות המסים אם נדרש לפתוח תיק עוסק פטור/מורשה וקבלות. Stripe עצמו גם יבקש פרטי זהות ובנק בהגדרת החשבון.
6. **ייעוץ משפטי:** תנאי השימוש ומדיניות הפרטיות הם נוסח ראשוני. כשיש חשבונות, התראות וואטסאפ וסוכן AI, כדאי שעורך דין יעבור עליהם (חוק הגנת הפרטיות, רישום מאגר מידע אם נדרש, דיני צרכנות וביטול עסקה).

## תשלומים (כשמוכנים)
- `STRIPE_SECRET_KEY` (מפתח live), `STRIPE_PRICE_ID`, `STRIPE_PRICE_ID_YEARLY`. התחילו במפתח `sk_test_` ובדקו כרטיס `4242 4242 4242 4242`, כולל ביטול ושחזור מנוי.

## אופציונלי
- `ANTHROPIC_API_KEY` לסוכן הצ'אט, עם תקרת הוצאה בחשבון ה-API.
- וואטסאפ (Meta): חשבון Business, `WA_*`, ותבנית מאושרת לתזכורות.

## תחזוקה
- **גיבוי:** `npm run backup` (קובץ `backup-*.db` ליד המסד). הריצו מהשל של Render ושמרו עותק מחוץ לדיסק, או הפעילו Snapshots של הדיסק ב-Render.
- **ניטור:** הוסיפו בדיקת זמינות חיצונית ל-`/healthz` (למשל UptimeRobot).
- **תלויות:** Dependabot ו-CodeQL כבר מוגדרים; `npm audit` רץ ב-CI.
- **נתוני חוק:** בתחילת כל שנה עדכנו את `public/js/tax-core.js` ו-`public/js/rights-core.js` מול מקור רשמי.

## קבלת פניות שירות לקוחות
כל פנייה נשמרת מוצפנת ב-DB, ובנוסף נשלחת אליכם מיד:
- **טלגרם (הכי פשוט, בלי דומיין):** פתחו בוט ב-@BotFather, שלחו לו הודעה כלשהי, וקבלו את ה-chat id מ-`https://api.telegram.org/bot<TOKEN>/getUpdates`. הגדירו `TELEGRAM_BOT_TOKEN` ו-`TELEGRAM_CHAT_ID`.
- **ntfy:** התקינו את אפליקציית ntfy, הירשמו לנושא ארוך וקשה לניחוש (מי שמכיר אותו יכול לקרוא), והגדירו `NTFY_TOPIC`.
- **מייל:** `SUPPORT_NOTIFY_TO` (או `SUPPORT_EMAIL`) יחד עם SMTP.
- **בלי הגדרה:** קריאה ידנית בשרת: `node scripts/tickets.js` (סימון כטופלה: `node scripts/tickets.js close 12`).
לענות למשתמש אפשר במייל שהוא השאיר (במייל ההתראה מוגדר Reply-To אליו).

## ממשק ניהול פניות (בעל האתר בלבד)
הגדירו `ADMIN_PASSWORD` (12 תווים ומעלה, ייחודית) ב-Render. אז `/admin.html` מציג את הפניות (חדשות/טופלו) ומאפשר לסמן כטופל. בלי הסיסמה הממשק כבוי לגמרי (404).
- אין קישור אליו באתר, והוא לא ב-sitemap ולא מאונדקס. הכניסה מוגבלת ל-5 ניסיונות כושלים ל-15 דקות, והסשן תקף 8 שעות. החלפת הסיסמה מנתקת את כל הסשנים.
- ממשק הניהול מציג פרטים אישיים של פונים: היכנסו רק ממכשיר שלכם והתנתקו בסיום.
