# תלוש בעברית

אתר שמאפשר להעלות תלוש שכר, סורק אותו (PDF עם טקסט, או תמונה באמצעות OCR בעברית) ומסביר כל סעיף: מה זה ולמה זה מופיע.

## הרצה
```bash
npm install
npm start        # http://localhost:3000
npm test
```

## אבטחה ופרטיות (מה כבר ממומש)
- קבצים נשמרים **בזיכרון בלבד** (multer memoryStorage), לא נכתבים לדיסק, ולא נרשמים ללוג.
- בדיקת סוג קובץ לפי תוכן (magic bytes), מגבלת גודל 8MB, קובץ אחד לבקשה, עד 6 עמודים ב-PDF.
- Helmet: CSP קפדני (ללא inline script/style), HSTS, `no-referrer`, `frame-ancestors 'none'`.
- הגבלת קצב (20 בקשות / 10 דקות ל-IP) ומגבלת עיבוד מקבילי; `Cache-Control: no-store` על ה-API.
- קבצי השפה של ה-OCR נארזים מקומית, בלי קריאות לרשתות חיצוניות בזמן ריצה.
- כל טקסט שמגיע מה-OCR מוצג ב-`textContent` בלבד (הגנה מפני XSS).

## לפני עלייה לאוויר
- להפעיל מאחורי HTTPS (Nginx / Cloudflare / PaaS) ולהגדיר `TRUST_PROXY=1` ו-`NODE_ENV=production`.
- להשלים פרטים ב-`privacy.html`, `terms.html`, `accessibility.html` (מסומנים בסוגריים מרובעים) ולהעביר לעורך דין.
- לבצע בדיקת נגישות מקצועית (ת"י 5568 / WCAG 2.1 AA) ובדיקת חדירות.
- לוודא שלוגים של שרת/פרוקסי לא שומרים גופי בקשות.

## מבנה
- `server.js`: שרת Express ו-API (`/api/analyze`, `/api/analyze-text`, `/api/glossary`)
- `src/glossary.js`: מילון המונחים וההסברים (קל להרחבה)
- `src/analyzer.js`: זיהוי סעיפים, סכומים ותובנות
- `src/extract.js`: חילוץ טקסט מ-PDF ו-OCR
- `public/`: ממשק (RTL, מצב כהה/בהיר, תפריט נגישות, רספונסיבי)

## רעיונות להמשך
השוואת תלושים בין חודשים, מחשבון נטו↔ברוטו, בדיקת נקודות זיכוי, תזכורות על זכויות (הבראה/חופשה), חשבונות משתמש עם הצפנה בצד לקוח, שפות נוספות.
